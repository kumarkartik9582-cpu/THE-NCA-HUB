Accessibility Statement

The NCA Hub is committed to ensuring digital accessibility for all users, including people with disabilities. We continually improve the user experience for everyone and apply relevant accessibility standards.

Conformance Status

We aim to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA. These guidelines explain how to make web content more accessible to people with disabilities. Conformance with these guidelines helps make the web more user-friendly for everyone.

Technical Specifications

This website relies on the following technologies for conformance with WCAG 2.1:

  • HTML5 with semantic landmark elements
  • CSS3 with prefers-reduced-motion and prefers-color-scheme support
  • WAI-ARIA where native HTML is insufficient
  • JavaScript with keyboard event support

Keyboard Navigation

This website is fully navigable using a keyboard. The following shortcuts are available:

Key Action
TabMove to next interactive element
Shift + TabMove to previous interactive element
Enter / SpaceActivate buttons and links
EscapeClose the AI chat widget or navigation menu
/Open site search
Arrow keysNavigate within menus and dialogs

Screen Reader Support

The NCA Hub has been tested with the following assistive technologies:

  • NVDA + Firefox (Windows)
  • VoiceOver + Safari (macOS and iOS)
  • TalkBack + Chrome (Android)

Known Limitations

While we strive for full WCAG 2.1 AA compliance, some known limitations exist:

  • AI Chat Widget: The chat widget requires JavaScript. Users who cannot use JavaScript may use email (thencahub@gmail.com) as an alternative contact method.
  • PDF Documents: Some downloadable documents may not be fully accessible. Contact us to request an accessible version.
  • Third-party content: Embedded content from external services (e.g., Payhip checkout) may not meet our accessibility standards. We are working with these providers to improve accessibility.
  • Complex animations: Some decorative animations are disabled for users with prefers-reduced-motion: reduce set in their operating system preferences.

Colour and Contrast

Our primary text meets or exceeds a 4.5:1 contrast ratio against background colours as required by WCAG 2.1 Level AA. Interactive elements have visible focus indicators. We do not rely on colour alone to convey information.

Forms and Interactive Elements

All form fields have associated labels. Error messages are announced to screen readers using ARIA live regions. Required fields are identified both visually and programmatically.

Images and Media

All meaningful images have descriptive alternative text. Decorative images are hidden from screen readers using aria-hidden="true". We do not use auto-playing audio or video.

Alternative Contact Methods

If you experience any difficulty accessing content on this website, the following alternatives are available:

  • Email: thencahub@gmail.com
  • Contact form: thencahub.com/contact

Report an Accessibility Issue

We welcome your feedback. If you encounter an accessibility barrier on this website, please contact us:

Email: thencahub@gmail.com

Please include the URL of the page where you experienced the issue, a description of the problem, and the assistive technology you were using (if applicable). We aim to respond within 5 business days.

Formal Complaints

If you are not satisfied with our response to your accessibility feedback, you may contact the Canadian Human Rights Commission or your provincial human rights tribunal.

Continuous Improvement

We review and update this accessibility statement annually. Our last comprehensive audit was conducted in March 2026. We are committed to ongoing improvements and welcome suggestions from our users.
