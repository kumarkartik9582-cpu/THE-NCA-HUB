# Payhip Practice Questions Setup Guide

**Time required:** 2–3 hours per subject (writing) + 15 minutes per upload
**Revenue potential:** $35–50 CAD per pack, 6 subjects = $210–300 per full-set buyer

---

## Step 1: Write Practice Questions

For each subject, create 5–10 practice questions that mirror the NCA exam format:
- Each question should be a 45-minute essay/problem-question style
- Include a fact pattern + specific legal issues to address
- Write in the style of Canadian law school exams

### Question Structure
```
QUESTION [N]:
[Fact pattern — 150-250 words describing a scenario]

Advise [party] on the following:
(a) [Legal issue 1]
(b) [Legal issue 2]
(c) [Legal issue 3]

[Total: 45 minutes]
```

### Model Answer Structure (IRAC)
```
MODEL ANSWER [N]:

ISSUE: [Identify the legal issue in 1-2 sentences]

RULE: [State the applicable Canadian law framework — cite cases]

APPLICATION: [Apply the rule to the specific facts — this is where marks are earned]

CONCLUSION: [Clear conclusion with practical advice]

[Key cases cited: Case 1, Case 2, Case 3]
[Estimated word count: 800-1200 words]
```

## Step 2: Format as PDF

1. Write in Google Docs or Word
2. Use consistent formatting: 12pt font, 1.5 line spacing
3. Include a cover page with: "NCA [Subject] Practice Questions — The NCA Hub"
4. Include a table of contents
5. Export as PDF

## Step 3: Upload to Payhip

1. Log in to [payhip.com/THENCAHUB](https://payhip.com/THENCAHUB)
2. Click **Add New Product**
3. Product type: **Digital Download**
4. Details:
   - Name: "NCA [Subject] Practice Questions & Model Answers"
   - Price: **$39 CAD** (or $45 if 10+ questions)
   - Description: "[N] practice questions in NCA exam format with full IRAC model answers. 45 minutes per question. Covers: [list key topics]."
5. Upload the PDF
6. Set category: "NCA Study Materials"
7. Save and publish
