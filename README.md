# The NCA Hub

A static website for NCA exam preparation, built for internationally trained lawyers qualifying in Canada through the National Committee on Accreditation (NCA) process.

## Description

The NCA Hub provides free guides, tools, and resources to help foreign-qualified lawyers pass the NCA challenge exams and obtain a Certificate of Qualification. The site covers all core and elective NCA subjects, exam strategy, study planning, and jurisdiction-specific guidance.

## Tech Stack

- **Frontend:** Vanilla HTML, CSS, JavaScript — no build framework, no bundler
- **Hosting:** Cloudflare Pages (auto-deploy from `main` branch)
- **Backend / API:** Cloudflare Functions (Workers) for the AI chat endpoint
- **Build system:** `build.js` (Node.js) — generates pre-rendered article pages from Markdown
- **Analytics:** Google Analytics 4 with Consent Mode
- **CDN / Security:** Cloudflare (edge caching, DDoS protection, WAF)

## Key Files

| File | Purpose |
|---|---|
| `index.html` | Homepage — hero, method section, readiness quiz, newsletter |
| `build.js` | Node.js script that converts `blog/article/*.md` files into pre-rendered HTML pages |
| `nca-chat-widget.js` | AI chat widget — sends messages to the Cloudflare Function backend |
| `nca-enhancements.js` | Site-wide enhancements: reading time, progress bar, scroll animations, GA4 event tracking, cookie consent banner |
| `sw.js` | Service worker — offline caching and update notifications |
| `sitemap.xml` | Auto-regenerated by `build.js` on each article build |
| `feed.xml` | RSS feed for blog articles |
| `functions/` | Cloudflare Functions directory — contains the AI chat API handler |

## Architecture

```
thencahub.com (Cloudflare Pages)
├── Static HTML/CSS/JS pages (served from edge)
├── /blog/[slug]/index.html  ← generated by build.js from Markdown
└── /functions/              ← Cloudflare Workers (AI chat backend)
```

The site is a **static site** — all HTML is pre-rendered and served directly from Cloudflare's edge network. There is no server-side rendering at request time. The only dynamic component is the AI chat widget, which calls a Cloudflare Function (`/functions/`) that proxies requests to an AI API.

## Development

No build step is required for most editing. You can edit HTML, CSS, and JavaScript files directly.

### Running locally

A simple local server is sufficient:

```bash
npx serve .
# or
python3 -m http.server 8080
```

### Generating article pages from Markdown

Article pages live as Markdown files in `blog/article/`. To regenerate the pre-rendered HTML:

```bash
node build.js
```

This will:
1. Read every `.md` file in `blog/article/`
2. Parse frontmatter and body content
3. Render each article into `blog/[slug]/index.html` with full SEO metadata, schema markup, and site chrome
4. Regenerate `sitemap.xml`

**Dependencies:** `build.js` optionally uses the `marked` npm package for Markdown parsing. If not installed, it falls back to a built-in minimal converter.

```bash
npm install marked   # optional — falls back gracefully if absent
```

## Deployment

Cloudflare Pages automatically deploys on every push to `main`. No manual deployment step is needed.

1. Push changes to `main`
2. Cloudflare Pages detects the push and deploys within ~1 minute
3. Changes are live globally via Cloudflare's edge network
